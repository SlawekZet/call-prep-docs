## Planned features

- **Auto-enrich new contacts** — trigger research when a new contact is created in HubSpot
- **Sync enriched fields** — write `summary`, `opening_talk`, `synergy_points` to custom HubSpot properties
- **Meeting prep trigger** — auto-research attendees 30 minutes before a scheduled meeting
- **Deal enrichment** — enrich contacts associated with open deals

## Workaround using n8n

Until the native integration is available, you can connect CallPrep to HubSpot using n8n.
See the [n8n integration guide](/integrations/n8n) for details.
