<Note>
  **There is no Slack integration.** An earlier version of CallPrep could post a
  summary to a Slack webhook; it was retired along with the scheduled HubSpot
  sync it belonged to, and nothing has replaced it.
</Note>

## What to use instead

- **Outreach activity** is written back onto the HubSpot contact timeline — see
  [HubSpot](/integrations/hubspot#what-lands-in-hubspot)
- **Meeting briefings** arrive by email before the call — see
  [Calendar and battlecards](/extension/calendar)
- **Anything else in Slack** can be built with the API and n8n — see
  [n8n](/integrations/n8n)

If a Slack app would genuinely change how your team works, tell us at
[hello@callprep.app](mailto:hello@callprep.app). It is not on the roadmap today,
and we would rather say so than keep a waitlist open.
