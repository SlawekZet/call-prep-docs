## Top-level response

| Field          | Type     | Description                                      |
|---------------|----------|--------------------------------------------------|
| `research_id` | string   | Unique job identifier                            |
| `status`      | string   | `queued` · `processing` · `completed` · `failed` |
| `completed_at`| string   | ISO timestamp when job completed (nullable)      |
| `error`       | string   | Error code if status is `failed` (nullable)      |
| `data`        | object   | Enriched data — present when `completed`         |

---

## data.prospect

| Field            | Type     | Description                                                |
|-----------------|----------|------------------------------------------------------------|
| `name`          | string   | Full name                                                  |
| `title`         | string   | Job title, translated to English                          |
| `company`       | string   | Current company name                                       |
| `email`         | string   | Work email address                                         |
| `linkedin_url`  | string   | LinkedIn profile URL                                       |
| `photo`         | string   | Profile photo URL (nullable)                               |

| `opening_talk`  | string[] | 3 conversation starters based on LinkedIn activity         |
| `posts`         | Post[]   | Up to 3 recent LinkedIn posts with AI summaries            |

### Post object

| Field      | Type    | Description                         |
|-----------|---------|-------------------------------------|
| `text`    | string  | Full post text                      |
| `posted`  | string  | Post date — `YYYY-MM-DD HH:MM:SS`   |
| `post_url`| string  | LinkedIn post URL (nullable)        |
| `summary` | string  | AI-generated one-sentence summary   |

  Decision makers are only available on **Growth and Scale plans**.
  On other plans, `decision_makers` will be an empty array.

## Nullable fields

Fields may be `null` when:
- The prospect was not found in any data source (some fields will still be populated from the email domain)
- LinkedIn posts were not available or the prospect has no public posts
- News items are older than 12 months or no news was found
- The plan does not include a specific feature

Always handle `null` values in your code.

```javascript
const summary = data.prospect?.summary ?? 'No summary available';
const dm      = data.decision_makers ?? [];
```
