## Initial release

CallPrep API is now available. Research your prospects before every sales call
with a single API call.

### Endpoints

- `POST /research` — Submit a prospect email and start enrichment
- `GET /research-status/{id}` — Poll for results

### Data sources

- **Apollo.io** — Prospect and company enrichment
- **People Data Labs** — Fallback prospect enrichment
- **RapidAPI LinkedIn** — Recent LinkedIn posts
- **Claude AI** — Insights, summaries, and discovery questions

### Plans

- **Free** — 3 credits to try
- **Starter** — $49/mo, 50 credits
- **Growth** — $149/mo, 200 credits, decision makers
- **Scale** — $349/mo, 600 credits, sales pitch, company news
